# Taiko no Matsuri

Jeu de rythme taiko tactile, bilingue français / anglais, pensé pour une PWA en plein écran paysage.

**Démo jouable :** https://taiko-no-matsuri.ebdkhai.chatgpt.site

## Points forts

- Deux zones tactiles seulement : bord bleu et centre rouge.
- Trois morceaux originaux avec difficultés et rythmes distincts.
- Jugement précis : Parfait, Bien, tôt, tard et manqué.
- Percussions Web Audio multicouches et accompagnement généré en temps réel.
- Interface kawaii japonaise, jauge segmentée nette et notes traversant la cible.
- PWA hors ligne, sans dépendance de jeu ni fichier audio externe.

## GitHub Pages

Le jeu est déjà prêt à être servi depuis la racine du dépôt. Dans **Settings → Pages**, choisissez **Deploy from a branch**, puis `main` et `/ (root)`.

## Originalité

Les graphismes, les rythmes et les sons procéduraux de ce projet sont originaux. Le jeu reprend les codes visuels et l’énergie des jeux de rythme taiko sans redistribuer leurs musiques ou assets protégés.
